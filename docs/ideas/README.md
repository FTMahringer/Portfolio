# Portfolio Ideas Index

This folder keeps only the ideas that still feel relevant for a personal portfolio and blog.

## Priority buckets

- `high.md` — strong candidates that directly improve the site for recruiters, companies, and readers
- `medium.md` — useful ideas, but not urgent
- `low.md` — optional polish or automation for later

## What this folder does not contain

Ideas that are clearly overkill for a portfolio site were intentionally left out. The goal is to keep the site focused on showcasing work, writing, and experience.

## Related plan

`docs/IMPLEMENTATION_PLAN.md` is the curated master plan. It keeps the important future work, especially automated resume generation, in one place.
